### Install

1. Download **`HabitTracker-v*.apk`** below on your Android phone (Android 5.0 or newer).
2. Open it. If asked, allow your browser or file manager to *install unknown apps*.
3. Tap the new **Habit Tracker** icon to log; long-press it for statistics.

Updating: install the new APK over the old one. Your data is kept.
The `.sha256` file holds the APK's checksum if you want to verify the download.
